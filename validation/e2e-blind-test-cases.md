# v0.2.0 独立盲测用例

每个用例由未参与实现的测试者以全新上下文执行。不给出路线答案或验收结论；只提供素材和用户请求。判定时检查：最多一次五问、主路线正确、假设明确、时长闭合、镜头提示词和验收可执行、声音/字幕/导出完整、无平台或付费生成承诺。

| ID | 用户请求 | 关键观察点 |
| --- | --- | --- |
| E2E-01 | 只有一句创意的 15 秒产品广告。 | 文字→视觉锚点、4 镜默认、完整制作包。 |
| E2E-02 | 有人物参考图的连续剧情短片。 | 参考图→一致性、身份锚点与连续性。 |
| E2E-03 | 保留动作和运镜的视频换场景。 | 视频为主路线、保留/变更合同。 |
| E2E-04 | 有明确首尾帧的 3 秒循环。 | 范围提醒、端点优先、循环验收。 |
| E2E-05 | 有旁白、字幕和音乐的 30 秒短片。 | 声音/字幕时间线、导出/发布检查。 |
| E2E-06 | 只优化一张图片提示词。 | 不启动完整工作流，路由到原子 Skill。 |
